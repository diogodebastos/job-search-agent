# Verified facts: the only source of CV and cover-letter claims

Rules:
- A claim goes in a CV, a cover letter, a form or a message **only** if it traces to a fact below.
- Every fact has an ID (for example `F-JOB1-02`) so Claude can cite it.
- Each fact says where it came from: `you, <date>` (you confirmed it in chat) or `document` (your old CV, a certificate, a public page).
- To retire a fact, strike it through. Don't delete it.
- Anything confidential (client names, internal numbers) is marked, with the wording that is allowed.

_This is an example for a fictional person. `/grill-cv` replaces it with yours._
