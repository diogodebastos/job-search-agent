# Cloudflare: visual language (studied 2026-11-18, cloudflare.com home)
- Colour: paper #FFFFFF, ink #262626, secondary #727272, hairlines #EAEAEA, one accent #FF5E1F (hover #FF7038, dark #BF4C14). Orange appears as solid panels and small dots, never as body text.
- Display and body: STK Bureau Sans (commercial), 500 for headings, sentence case, tight negative tracking (-0.025em), 56px hero. Substitute: Inter.
- Labels and UI snippets: Apercu Mono Pro 12px (commercial). Substitute: DM Mono.
- Layout: a blueprint. Hairline cells that share borders, tiny square handles on box corners, dashed guide lines down the page margins, dot-grid bands, pill chips and pill buttons, generous white.
- Imagery: no illustration. UI diagrams instead: agent logs in mono ("3 background agents launched"), dashed flow boxes with line icons, a white-vs-orange two-panel comparison, an orange closing panel with a dot texture and a warm glow rising from the bottom edge.
- Signatures: orange rounded-square app icon, orange status dots, check-mark status pills, ticker row of icon + phrase.
- Mapping: nav row (a personal icon, links, orange pill for email); centred name as the hero; two-panel row with the summary in the white cell and a true "agent log" of the candidate's own projects in the orange panel; every CV section a hairline cell with corner handles; skills stay as text lines (parsers); orange closing panel on the letter.
- Not used: the cloud logo, the CLOUDFLARE wordmark, their icons, their copy ("Build without boundaries").
